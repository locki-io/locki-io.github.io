# The four books — covers

Act 0 (void → 0): four books open as light around the point of power.
Drop the cover scans here, one PNG per book, front cover only:

| file | book | author |
|---|---|---|
| `goldratt.png`   | The Goal                      | Eliyahu M. Goldratt |
| `whitman.png`    | Leaves of Grass               | Walt Whitman |

Any size; portrait; sRGB. The stage reads the aspect ratio from the image
itself, so no cropping is needed — a phone photo of the physical cover is
enough. Missing file → a dark cover with the title drawn in light.
